The tools and people behind Noto.

Apple frameworks

Noto is built with Apple’s frameworks and its own InkLab handwriting engine. The one outside library it includes is Google Sign-In, used only if you choose to sign in with Google, together with the open-source code that library relies on (listed below).

  • SwiftUI and UIKit for the interface.
  • Metal and PencilKit for drawing and Apple Pencil support.
  • PDFKit for working with PDFs, and AVFoundation for audio.
  • Vision and Core Spotlight for on-device recognition and search.
  • StoreKit for App Store purchases.
  • AuthenticationServices for Sign in with Apple, and PhotosUI for choosing a profile photo.

The interface also uses Apple’s SF Symbols.

Open-source software

Optional sign-in with Google uses Google Sign-In for iOS and the libraries it depends on. Each is distributed under the Apache License, Version 2.0.

  • Google Sign-In for iOS
  • AppAuth for iOS
  • GTMAppAuth
  • GTM Session Fetcher
  • App Check Core
  • GoogleUtilities
  • Promises
  • Interop for Google SDKs

InkLab

InkLab is Noto’s handwriting engine, responsible for capturing and rendering the ink you write.
